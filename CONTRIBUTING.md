# Contributing

## Changes

Open an issue for a bug report or feature request. Small maintenance, documentation and infrastructure changes can go directly to a pull request.

Use `type(scope): subject` for commit and pull request titles.

Use the Why, What and Validation sections to explain the change and report relevant checks. Link related issues when applicable. For comparisons, include the revisions, conditions and results needed to reproduce them.

## Sign-off

Read the [Developer Certificate of Origin 1.1](https://developercertificate.org/) and sign off every commit with `git commit -s`, using the name and email of the commit author. Contributions use [Apache-2.0](LICENSE). Preserve relevant sign-offs when squashing.
